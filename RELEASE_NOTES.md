# Summa v1.0.0 (beta)

Summa is a reading-augmentation tool for macOS. It highlights text in real
time and surfaces Wikipedia context and dictionary definitions inline —
historical, conceptual, and linguistic context without tab-switching,
pop-ups, or distraction loops.

**This is an early public beta.** Feedback welcome via Issues.

### Install (macOS)
1. Download `Summa-1.0.dmg` below.
2. Open it and drag **Summa** to Applications.
3. Launch it — the build is signed and notarized by Apple, so it opens
   normally with no security workaround.

### Try it without installing
Live interactive demo: https://summa-demo.josephruocco.net
